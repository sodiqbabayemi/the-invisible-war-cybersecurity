## Overview

**The Invisible War — Volume I: The Invisible Attacker** is a cybersecurity learning publication authored by **Sodiq Adewale Babayemi** and published by **AI Info Tech Learning**.

The book introduces offensive cybersecurity through a combination of cybersecurity concepts, attacker perspectives, ethical security practices, practical laboratories, and guided learning exercises.

This repository presents a **selected portfolio preview** of the work. It does **not** contain the complete manuscript.

## Practical Learning Environment

The practical sections emphasize **authorized and controlled environments** for cybersecurity experimentation.

Example laboratory environments include:

* Kali Linux
* OWASP Juice Shop
* VirtualBox
* Intentionally vulnerable training applications

The objective is to develop security knowledge without encouraging unauthorized access to real-world systems.

## Ethical & Safety Notice

All practical cybersecurity activities described in this portfolio are intended for:

* Education
* Research
* Authorized security testing
* Controlled laboratory environments

Users should only test systems they own or have explicit permission to assess.
